## Duplicate logic and console statements

Repeated sidebar profile/Settings return handling across five pages, four meal-card sections in Food Tracker, color maps in Calendar/Overview/Statistics versus color-utils, legacy vs hook goal aggregations, and independent storage synchronization are consolidation candidates. Each needs domain fixtures before extraction. Some calculations intentionally differ (7-day vs all-time, current vs historical goal); do not unify by appearance. GoalCircle currentValue and many focus flags/imports appear unused but are not proof that their surrounding capability should disappear. Preserve public props until consumers and UI intent are verified. Sensitive journal logging is FC-002; food/search diagnostics merit a narrow privacy patch. Keep meaningful storage errors visible.

Generating sources: Vite and scripts generate ignored dist assets/worker/test-dock HTML; do not commit dist. The tracked lockfile should remain committed for npm ci. Current food dataset is a curated/cleaned historical generator output with no demonstrated reproducible final pipeline; retain until provenance is established. Generated historical geometry JSON/screenshots should remain reference artifacts with their original environment labels.
